오프닝: PIERR는 사람의 물리적 상호작용을 추출하고 선택한 로봇에 리타게팅해 검증된 학습 데이터로 변환합니다.
01 · Problem

로봇 학습 데이터는
비싸고, 느리고, 로봇마다 다릅니다.

01

Teleoperation

숙련 작업자가 실제 로봇을 반복 조종해야 합니다.

02

Robot-specific

같은 태스크도 로봇 관절과 제약이 달라 재사용이 어렵습니다.

03

Scale

수백·수천 episode를 모으는 순간 비용이 폭증합니다.

타깃 고객은 로봇은 있지만 특정 태스크의 대규모 데이터가 없는 연구실과 로봇 회사입니다.
02 · Solution

사람은 카메라 앞에서 작업하고,
우리는 로봇 데이터로 컴파일합니다.

3인칭
RGB 영상
→
손 landmark
+ grasp phase
→
Object-centric
EE trajectory
→
Franka IK
+ MuJoCo 검증

입력

고객의 로봇 사양, URDF/제약, 태스크 정의, 촬영 영상

출력

7-DoF joint target, gripper, provenance, validation, rollout MP4

중요: 영상에서 바로 관절각을 추출하는 것이 아닙니다. 영상은 task phase를 주고, 고객 장면과 로봇 제약으로 실행 가능한 trajectory를 컴파일합니다.
한 장 요약: 고객은 로봇과 태스크를 정의합니다. Dataminer는 사람 촬영부터 물리 검증과 데이터 확장까지 수행해 검증된 데이터셋을 납품하고, 고객이 그 데이터로 정책을 학습합니다.

05 · Learning

Phase-conditioned Behavior Cloning

31-D

Observation

robot state · object/target relative pose
7-phase one-hot · phase progress
→
3 × 512

MLP Policy

chunk = 1
매 control step 재추론
→
8-D

Action

7 absolute joint targets
+ gripper command
최종 합격 기준: 학습과 분리된 20개 환경 중 10개 이상 성공. 미달 시 성공 영상만 골라 통과 처리하지 않습니다.
기존 delta action 누적오차를 줄이기 위해 absolute joint target과 매 스텝 재추론으로 변경했습니다.
