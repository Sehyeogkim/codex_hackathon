# 데모 1 촬영 가이드

## 태스크

손잡이 없는 무광 병 또는 머스터드 병을 A에서 집어 B로 옮긴 뒤 잠시 유지한다.

## 물체와 작업 영역

- 빈 병을 사용한다. 권장 크기는 지름 5~6cm, 높이 7~12cm다.
- 병은 불투명·무광이어야 하며 테이블과 대비되는 색을 사용한다.
- 투명하거나 반사되는 병, 손잡이가 있는 물체는 사용하지 않는다.
- 카메라 화면 기준 왼쪽에 A, 오른쪽에 B를 표시한다.
- A와 B는 카메라에서 같은 깊이에 두고 중심 간격을 30cm로 맞춘다.
- A/B 주변 40×30cm 직사각형의 네 모서리에 5cm ArUco marker 4개를 붙인다.
- 손과 병이 marker를 오래 가리지 않게 한다.

## 카메라

- 스마트폰 후면 메인 1× 카메라를 가로 방향으로 삼각대에 고정한다.
- 카메라는 A/B 중점 정면에 둔다. 수평 각도는 `yaw 0°`, 좌우 기울기는 `roll 0°`다.
- 렌즈 중심은 테이블 표면보다 70cm 높게 둔다.
- 카메라와 A/B 중점 사이의 수평거리는 100cm로 둔다.
- 렌즈를 A/B 중점으로 향하게 하여 하향 각도를 35°로 맞춘다.
- 1920×1080, 30fps, H.264로 촬영한다.
- 자동 초점과 노출을 작업 영역에 고정하고 줌·카메라 이동은 하지 않는다.
- 손, 병, A/B, ArUco marker 4개가 영상 안에 들어오는지 확인한다.

허용 오차는 높이·거리 ±5cm, yaw·roll ±5°, 하향 각도 ±3°다.

## 수행 순서

1. 오른손을 프레임 안의 고정된 rest 위치에 두고 1초간 정지한다.
2. 손을 A의 병으로 1.5초 동안 이동한다.
3. 병 몸통을 수직으로 잡고 0.5초간 정지한다.
4. 병을 1초 동안 수직으로 10cm 들어 올리고 0.5초간 정지한다.
5. 같은 높이와 깊이를 유지하며 2초 동안 B까지 수평 이동한다.
6. 병을 B 위에서 0.5초간 유지한다.
7. 병을 1초 동안 수직으로 내려놓고 0.5초간 정지한다.
8. 병을 놓고 손을 rest 위치로 되돌린 뒤 1초간 정지한다.

전체 동작은 9~11초로 수행하고 같은 조건으로 3~5회 촬영한다.

## 배치도

위에서 본 모습:

```text
                 참가자

┌──────────────────────────────┐
│ M0    A ● ──── 30cm ──── ● B    M1 │
│ M2                            M3 │
└──────────────────────────────┘
                 ↑ 광축 (yaw 0°)
                 │ 100cm
               CAMERA
```

옆에서 본 모습:

```text
CAMERA ●  렌즈 높이: 테이블 +70cm
        \
         \ 35° 하향
          \
───────────●────────────────── 테이블
          A/B 중점
      수평거리 100cm
```

## 주의사항

- 병을 기울이거나 회전하지 않는다.
- 이동 중 병과 손을 몸이나 팔로 가리지 않는다.
- A→B 이동은 카메라에 대해 좌우 방향으로만 수행한다.
- 촬영 중 병의 깊이를 카메라 방향으로 바꾸지 않는다.
- 조명이 밝고 일정한 곳에서 촬영하고 테이블 위 불필요한 물체는 치운다.
- 녹화 시작 후 스마트폰을 만지지 않는다.
