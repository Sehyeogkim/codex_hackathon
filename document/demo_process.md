## 2. 기술 파이프라인

```
[영상 mp4]
   │  MediaPipe Hand Landmarker (사전학습, 학습 불필요)
   ▼
[손 랜드마크 21개 × T프레임]  ─ 손목 위치, 엄지-검지 거리
   │  정규화 + 결측 보간 + Savitzky-Golay 평활
   ▼
[정규화된 손 궤적]
   │  리타게팅: 이미지 x→로봇 y, 이미지 y→로봇 z, 손바닥 크기→로봇 x(깊이)
   │            엄지-검지 거리→gripper (히스테리시스로 이진화)
   ▼
[EE 궤적 (T, 8): xyz + quat + grip]   ◄── 로봇 무관 중간 표현
   │  Damped Least Squares IK (Franka 7-DoF)
   ▼
[관절 궤적 (T, 8): joint1..7 + gripper]
   │  MuJoCo 물리 재생
   ▼
[검증]  joint limit / 자기충돌 / 저크 / 태스크 성공
   │  통과한 것만
   ▼
[데이터셋]  LeRobot parquet + mp4  ─ front/wrist 카메라 2종
   │
   ▼
[BC 정책 학습]  →  새 컵 위치에서 성공률
```

**설계 원칙 두 가지**
- **EE 궤적이 중간 표현이다.** 로봇이 바뀌면 IK 단계만 교체한다. 고객 로봇 사양 대응이 곧 이 지점이다.
- **어디에도 우리가 학습시키는 모델이 없다.** MediaPipe는 남의 사전학습 모델, IK는 기하학, MuJoCo는 물리엔진. 마지막 BC만 학습이고 그건 "데이터가 학습 가능함"을 증명하는 용도다.

## 7. 정직하게 말할 것

심사위원이 아는 사람이면 다음을 물어본다. 먼저 꺼내면 신뢰가 되고, 숨기면 반박이 된다.

- **"단안 깊이는 추정 아닌가?"** → 맞다. 손바닥 크기 기반 역깊이 단서를 쓴다. 캘리브레이션이나 뎁스 카메라로 개선되는 문제고, 우리 사업 모델은 애초에 **촬영 환경을 우리가 구성**하므로 실제 운영에서는 캘리브레이션된 다중 카메라를 쓴다.
- **"이거 MimicGen 아닌가?"** → MimicGen은 소스가 텔레옵 시연이다. 우리 소스는 사람 영상이라 로봇도 조종 장비도 필요 없다.
- **"수율이 얼마나 나오나?"** → 오늘 측정한 숫자를 그대로 말한다. 검증 통과율을 슬라이드에 넣는다. 낮으면 낮은 대로 말하고, 그게 왜 문제가 아닌지(생성 비용은 싸고, 통과한 데이터의 품질은 유지된다) 설명한다.
